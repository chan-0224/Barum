# 성분 조합 룰 — 출처 기준

`ingredient_rules.csv`가 유일한 원본이다. 여기서 뺀 룰은 `scripts/load_rules.py`가 DB에서도 지운다.

## 등급

| level | 뜻 | 배지 문구 |
|---|---|---|
| `AVOID` | **같은 시간대에** 함께 쓰지 않기 (제품을 버리라는 뜻이 아니다) | 같이 쓰지 마세요 |
| `CAUTION` | 아침·저녁 분리 등 조건부 | 시간대를 나눠 쓰세요 |
| `GOOD` | 함께 쓰면 시너지 | 함께 쓰면 좋아요 |

## 출처 선택 원칙

성분 조합은 **업계 의견이 실제로 갈린다.** 그래서 등급에 따라 어느 쪽을 따를지 미리 정해 뒀다.

- **AVOID·CAUTION(안전 판정) — 보수적인 출처를 따른다.** 한쪽이라도 "자극 위험이 있으니 나눠 쓰라"고 하면 그 판정을 채택한다. 틀렸을 때의 비용이 비대칭이다. 안 겹쳐 쓰게 해서 잃는 건 편의뿐이지만, 겹쳐 쓰게 해서 잃는 건 사용자의 피부다.
- **GOOD(시너지 판정) — 합의된 출처만 따른다.** 한 곳이라도 반대하면 넣지 않는다. 권장은 근거가 확실할 때만 한다.

### 실제로 갈린 사례 — 레티놀 + 산/비타민C

| 출처 | 입장 |
|---|---|
| The Ordinary 공식 가이드 | 레티노이드 + 직접 비타민C·직접 산 → 민감성 위험, 저녁을 번갈아 쓰라 |
| Paula's Choice | 같이 써도 된다. AHA/BHA가 레티놀을 비활성화한다는 연구는 없다 |

**두 쪽이 서로 다른 것을 말한다.** Paula's Choice가 부정하는 건 "효과가 상쇄된다"는 주장이고, The Ordinary가 경고하는 건 "자극이 누적된다"이다. 후자는 어느 쪽도 부정하지 않는다.

→ 위 원칙대로 **AVOID를 유지**하되, 이유 문구에서 반박된 주장("산도가 달라 효과가 줄어든다")은 제거했다. 지금 남은 근거는 자극뿐이다.

### 통설을 뒤집은 사례 — 나이아신아마이드 + 아스코빅애씨드

"같이 쓰면 안 된다"가 널리 퍼져 있지만 Paula's Choice 원문은 **안전하며 오히려 이롭다**고 한다. 1960년대 연구를 잘못 해석한 것이고, 그 연구는 비안정화 형태를 썼다.
→ 통설을 따르지 않고 **GOOD**으로 넣었다. 근거가 확실한 쪽을 택한다.

## `verified` 컬럼

원문을 직접 열어 확인했는지 여부.

- `true` — **발표·IR 자료에 인용해도 되는 것.** URL이나 DOI까지 CSV에 들어 있다
- `false` — 기관·저자명 수준까지만 확인. 판정 근거로는 쓰되 **인용하지 말 것**

**AVOID·CAUTION은 전부 `true`여야 한다.** 안전 판정이 확인 안 된 근거 위에 서 있으면 안 된다.

## 룰을 추가·수정할 때

1. 성분명은 반드시 `ingredients.std_name` 표준명. 구어체 금지 (`히알루론산` ✗ → `하이알루로닉애씨드` ✓)
   - DB에 없으면 FK가 적재를 막는다. 실제로 벤조일퍼옥사이드·아젤라익애씨드·하이드로퀴논이 여기서 걸렸다 (셋 다 국내에서는 의약품이라 화장품 원료 목록에 없음)
2. 근거를 못 찾으면 **넣지 않는다.** 확인 못 한 근거로 채우는 것보다 건수가 적은 게 낫다
3. `python scripts/load_rules.py --check-only` 로 검증 → 통과하면 `--check-only` 빼고 적재
4. `reason`은 한 문장. 사용자에게 그대로 보인다. 병명 진단 표현 금지 (CLAUDE.md 원칙 3)

## 제외된 조합과 이유

| 조합 | 왜 뺐나 |
|---|---|
| 벤조일퍼옥사이드 + 레티놀 | 벤조일퍼옥사이드가 국내 화장품 원료가 아니다(의약품). DB에 없어 매칭 불가 |
| 3-O-에틸아스코빅애씨드 + 레티놀 | The Ordinary는 **직접** 비타민C(LAA)만 conflict로 본다. 유도체는 호환으로 분류 |
| 하이알루로닉애씨드 + 세라마이드엔피 | 두 성분을 **비교한** 연구는 있으나 조합의 시너지를 다룬 근거를 못 찾음 |
| 글라이콜릭애씨드 + 세라마이드엔피 | 출처가 블로그·자동생성 페이지 수준이라 인용 불가 |
| 산 + 산 (글라이콜릭+살리실릭, 락틱+살리실릭, 만델릭+살리실릭) | "각질 제거 산을 겹쳐 쓰지 말라"는 통념은 널리 퍼져 있으나, The Ordinary 공식 가이드 어디에도 **산끼리의 조합**은 서술돼 있지 않다. 레티노이드+산과 비타민C+산만 다룬다. 근거를 찾으면 다시 넣을 후보 |

## 현재 CAUTION 룰이 0건이다

산+산 3건을 빼면서 CAUTION 등급이 비었다. **등급 정의 자체에 문제가 있어서 방치 중이 아니라 드러난 것이다.**

- `AVOID` = 같은 시간대에 함께 쓰지 않기
- `CAUTION` = 아침/저녁 분리 등 조건부

둘이 사실상 같은 말이다. 출처들도 "avoid ... 쓰려면 아침/저녁으로 나눠라"처럼 한 문장에 둘을 같이 말한다.
→ 등급을 둘로 나눌지, `AVOID`/`GOOD` 두 단계로 줄일지 결정이 필요하다. `docs/API.md`의 `conflict.level` enum과 화면 배지가 여기 걸려 있다.
