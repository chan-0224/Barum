# 바름 화면 명세

디자인 시안·프론트 구현·API의 공통 기준. 화면 13개, 하단 탭 3개(오늘/화장대/기록), 로그인 화면 없음.

---

## 전역 규칙

- **세션**: 최초 진입 시 익명 세션 자동 발급
- **샘플 화장대**: 최초 진입 시 데모용 제품 12~15개 자동 세팅. 상단에 "체험용 화장대" 배지 상시 표시
  - 구성: 클렌저·토너·세럼·크림·선크림을 고루 채우고, **AVOID 조합이 최소 1쌍 포함**
- **샘플 → 내 화장대 전환**: 첫 제품 등록 시 샘플 전체 제거 + 토스트("체험용 제품이 정리되었습니다"). 섞지 않는다
- **뒤로가기**: 하위 화면은 상단 좌측 뒤로가기. 탭 전환 시 스크롤·입력 상태 유지하지 않음
- **위치**: 브라우저 geolocation 요청. 거부 시 서울 좌표 폴백 + "서울 기준" 표기
- **에러 공통**: 네트워크/서버 오류는 화면 중앙 안내 + 재시도. 페이지 이동 없음

## 1. 오늘 (홈) — 탭 1, 기본 진입점

| | |
|---|---|
| **목적** | 진입 즉시 "오늘 뭘 바를지" 확인 경로 제시 |
| **필수 요소** | 오늘 날짜·요일 / 날씨 요약(기온·습도·미세먼지) / 큰 CTA "오늘의 루틴 받기" / 체험용 배지 / 최근 기록 1건 미리보기(있을 때) |
| **예외** | 날씨 조회 실패 → 날씨 영역만 "정보를 불러오지 못했습니다", CTA는 정상 동작 |
| **다음** | CTA → 셀카 촬영 |

## 2. 셀카 촬영

| | |
|---|---|
| **목적** | 피부 컨텍스트 입력. 선택 단계임을 명확히 |
| **필수 요소** | 전면 카메라 뷰 / 촬영 버튼 / 갤러리에서 선택 / **"오늘은 건너뛰기"** / 안내문("사진은 나만 볼 수 있어요") |
| **예외** | 카메라 권한 거부 → 갤러리 선택만 노출 / 건너뛰기 → 날씨+화장대만으로 루틴 생성 |
| **다음** | 분석 로딩 |

## 3. 분석 로딩

| | |
|---|---|
| **목적** | 3~5초 대기의 체감 품질 관리 |
| **필수 요소** | 진행 애니메이션 / 단계 텍스트("피부 상태 확인 중" → "오늘 날씨 반영 중" → "화장대에서 고르는 중") |
| **예외** | 10초 초과 → "조금만 더 기다려 주세요" / 30초 초과·실패 → 오류 + 재시도 |
| **다음** | 완료 시 루틴 카드 자동 전환 |

## 4. 루틴 카드 ★ 킬러 화면

| | |
|---|---|
| **목적** | 서비스의 전부. 100초 시연 영상의 중심 |
| **필수 요소** | 날씨 한 줄 요약 / 피부 컨텍스트 한 줄(건너뛴 경우 생략) / **바를 것: 순번 + 제품명 + 한 줄 이유 3~4개** / **뺄 것: 제품 1~2개 + 이유** / 충돌 경고 배지(해당 시) / "기록 저장" 버튼 |
| **동작** | 텍스트가 스트리밍으로 순차 노출 |
| **예외** | 보유 제품 0개 → "화장대를 먼저 채워주세요" + 화장대 탭 CTA / 생성 실패 → 재시도 |
| **다음** | 기록 저장 → 기록 탭 |

## 5. 충돌 경고 (루틴 카드 내 배지)

| | |
|---|---|
| **형태** | 독립 화면 아님. 카드 위 배지 + 펼침 영역 |
| **필수 요소** | 경고 아이콘 + 조합명("레티놀 + 비타민C") + 판정 문구("같이 쓰지 마세요") / 펼치면 이유 + **근거 출처** |
| **등급** | `AVOID`("같이 쓰지 마세요") / `GOOD`("함께 쓰면 좋아요") **2단계뿐.** 아침 루틴만 제시하므로 "시간대를 나눠 쓰세요"는 성립하지 않아 폐지 |
| **예외** | 충돌 없음 → 배지 미표시(빈 영역 남기지 않음) |
| **연동** | 경고에 등장한 성분은 "뺄 것" 항목과 내용이 이어져야 함 |

## 6. 화장대 — 탭 2

| | |
|---|---|
| **필수 요소** | 제품 목록(브랜드, 제품명, 주요 성분 2~3개) / "제품 추가" 버튼 / 체험용 배지(샘플 상태일 때) |
| **예외** | 빈 상태 → 일러스트 + "첫 제품을 등록해 보세요" + 추가 CTA |
| **다음** | 추가 → 등록 방식 선택 / 항목 탭 → 제품 상세(성분 목록, 삭제) |

## 7. 등록 방식 선택

| | |
|---|---|
| **필수 요소** | **제품 검색으로 등록**(권장 표시) / **전성분표 사진으로 등록** 두 카드, 각 한 줄 설명 |
| **다음** | 각각 8 / 9번 |

## 8. 제품 검색 등록 (주 경로)

| | |
|---|---|
| **목적** | 구축된 제품 카탈로그에서 골라 등록 |
| **필수 요소** | 검색창(제품명·브랜드) / 카테고리 필터(클렌저·토너·세럼·크림·선크림) / 제품 항목(브랜드, 제품명, 주요 성분 2~3개) / 다중 선택 / 하단 "N개 추가" |
| **예외** | 검색 결과 0건 → "찾는 제품이 없나요? 전성분표 사진으로 등록해 보세요" + 9번 CTA |
| **다음** | 화장대 목록 (확인 단계 없음) |

## 9. 전성분표 사진 등록 (보조 경로)

| | |
|---|---|
| **목적** | 카탈로그에 없는 제품(직구·소분·신제품) |
| **필수 요소** | 카메라/갤러리 / 촬영 가이드("제품 뒷면 또는 포장 박스의 전성분표") / 예시 이미지 / 제품 별칭 입력 |
| **예외** | **인식 실패 전용 화면**: "글씨를 읽지 못했어요" + 다시 촬영 / 제품 검색으로 전환 CTA |
| **다음** | 인식 결과 확인 |

## 10. 인식 결과 확인 (사진 등록 전용)

| | |
|---|---|
| **목적** | 인식 결과를 보여주고 저장 여부만 선택 |
| **필수 요소** | 제품 별칭 / 인식된 성분 목록(**읽기 전용, 수정 불가**) / **저장** / **다시 촬영** |
| **예외** | 성분 0건 → 저장 비활성, 다시 촬영만 |
| **다음** | 저장 → 화장대 목록(+ 샘플 제거 토스트, 최초 1회) / 다시 촬영 → 9번 |

## 11. 기록 (타임라인) — 탭 3

| | |
|---|---|
| **필수 요소** | 날짜순 리스트(썸네일, 날짜, 날씨 요약, 루틴 요약 한 줄, 경고 표시) |
| **예외** | 기록 0건 → "첫 기록을 남겨보세요" + 오늘 탭 CTA |
| **다음** | 일자 상세 |

## 12. 일자 상세

| | |
|---|---|
| **필수 요소** | 그날 셀카(있을 때) / 날씨 / 루틴 전문(바를 것·뺄 것) / 충돌 경고 이력 / 삭제 |

## 13. 설정 (헤더 진입, 탭 아님)

| | |
|---|---|
| **필수 요소** | 위치 설정(자동/수동) / **내 데이터 전체 삭제**(사진 포함, 확인 다이얼로그) / 개인정보 처리 안내 / 서비스 정보 |

## 디자인 토큰 (루틴 카드 시안 기준)

- 배경: 오프화이트 / 메인: 세이지 그린 / 경고: 코랄 / 강조 버튼: 딥그린
- 큰 라운드, 넉넉한 여백, 카드 중심 구성
- 떠 있는 하단 탭 3개

## 개발 우선순위

| 순위 | 화면 |
|---|---|
| 1 | 4 루틴 카드 + 3 로딩 |
| 2 | 1 오늘 + 2 셀카 |
| 3 | 8 제품 검색 등록 (카탈로그 DB 선행) |
| 4 | 6 화장대 (목록·빈 상태) |
| 5 | 9·10 사진 등록 |
| 6 | 11·12 기록 |
| 7 | 13 설정 |

## 디자인 제작 순서

1. 루틴 카드 (톤·토큰 확정) ✅
2. 분석 로딩
3. 오늘 → 화장대(빈 상태 포함) → 제품 검색 → 사진 등록 → 기록 → 설정
4. 공통: 충돌 경고 배지, 체험용 배지, 빈 상태, 에러 상태
